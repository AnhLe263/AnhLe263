# About Me

I am a nuclear physicist and scientific software developer working in Monte Carlo particle transport simulation, accelerator physics, radioisotope production, and scientific computing.

My work focuses on:

- Geant4 and Geant4-DNA development
- Monte Carlo radiation transport simulation
- Nuclear physics and ít applications
- Scientific computing workflows
- High-performance scientific simulation
